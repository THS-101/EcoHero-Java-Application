♻️ EcoHero
====================================================
###Recycling & Waste Management 
###Learning Application

A Java Swing desktop application designed to educate users about recycling and responsible waste management through interactive learning materials, quizzes and rewards.

##Features
- Environmental learning modules.
- Interactive quizzes with three question types.
- Score calculation and reward badges.
- Persistent leaderboard using file handling.
- User-friendly graphical interface.

##Technologies
- Java
- Java Swing
- Object-Oriented Programming
- File Handling
- Exception Handling

How to run in PowerShell:
1. Open the extracted folder that contains all .java files.
2. Compile:
   javac .\*.java
3. Run:
   java EcoHeroApp

If wildcard fails in your PowerShell, use:
   cmd /c "javac *.java"
   java EcoHeroApp
